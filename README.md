# Site LGI Engenharia de Avaliações

Projeto pronto para Vercel usando React + Vite.

## Como publicar na Vercel

1. Crie um repositório no GitHub, por exemplo: `lgi-site`.
2. Envie todos os arquivos desta pasta para esse repositório.
3. Na Vercel, escolha **Add New Project**.
4. Conecte o GitHub e selecione o repositório.
5. Em Framework Preset, selecione **Vite**.
6. Clique em **Deploy**.
